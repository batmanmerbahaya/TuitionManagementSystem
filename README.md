# Anjung Ilmu Tuition Management System

Tuition management system for Pusat Tuisyen Anjung Ilmu Pendeta, built with **Laravel 13 (PHP 8.5) and
MySQL 8**: student registration for subjects and packages, timetables, monthly billing, payment proof
upload and verification, and admin / teacher / student dashboards.

The app is in [`tms-laravel/`](tms-laravel/). See [`tms-laravel/README.md`](tms-laravel/README.md) for how
to install and run it, the list of pages and features, and the tests.

No passwords are stored in this repository: copy `tms-laravel/.env.example` to `tms-laravel/.env` and put
the database and Gmail settings there (`.env` is ignored by git).
